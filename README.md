# Sugar Coated Dreams by Roshan Rakitha

A modern, beautiful, and mobile-responsive website designed specifically for party chef branding. Built with HTML5, CSS3, and vanilla JavaScript, featuring a playful dessert-themed design that showcases Roshan Rakitha's sweet creations and party catering services.

## 🌟 Features

- **Ultra-Modern Design**: Cutting-edge glassmorphism effects with vibrant gradient backgrounds
- **Advanced Animations**: Smooth scroll-triggered animations, magnetic buttons, and floating elements
- **Mobile Responsive**: Optimized for all devices with touch-friendly modern interactions
- **Contemporary UI**: Minimalist design with bold typography and contemporary color schemes
- **Interactive Elements**: Custom cursor effects, parallax scrolling, and 3D hover animations
- **Party Chef Focus**: Sections designed to showcase sweet creations and celebration services
- **Contact Form**: Functional contact form with party event options
- **SEO Optimized**: Semantic HTML structure for better search engine visibility

## 🚀 Quick Start

1. **Open the website**: Simply open `index.html` in your web browser
2. **Customize content**: Edit the HTML file to replace placeholder content
3. **Add images**: Place your photos in the `images/` folder and update image paths
4. **Personalize styling**: Modify `css/style.css` for brand colors and styling

## 🎨 Customization Guide

### Personal Information
Replace all instances of `[Name]`, `[Year]`, and placeholder contact information:

```html
<!-- In index.html -->
<title>Chef [Your Name] - Personal Culinary Artist</title>
<h1 class="hero-title">Crafting Culinary Art Since [Year]</h1>
<p><strong>Email:</strong> chef@yourname.com</p>
<p><strong>Phone:</strong> (555) 123-4567</p>
<p><strong>Location:</strong> [Your City, State]</p>
```

### Images
Replace placeholder images with your actual photos:

1. **Hero Image**: Update `.chef-image-placeholder` with your professional portrait
2. **About Section**: Add your kitchen/workspace photo
3. **Portfolio**: Add photos of your signature dishes
4. **Gallery**: Include food photography and behind-the-scenes shots
5. **Testimonials**: Add client photos (or use initials/logos)

### Color Scheme
Customize the color palette in `css/style.css`:

```css
:root {
    --primary-color: #8b4513;     /* Saddle Brown */
    --secondary-color: #d2691e;   /* Chocolate */
    --accent-color: #daa520;      /* Goldenrod */
    --text-dark: #2c1810;         /* Dark Brown */
    --text-light: #8b7355;        /* Tan */
    --cream: #faf7f2;             /* Cream */
    --white: #ffffff;             /* White */
}
```
